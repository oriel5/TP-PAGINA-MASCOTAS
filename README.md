# Pagina web de veterinaria

Proyecto web desarrollado con HTML y CSS para la gestion y visualizacion de mascotas para una veterinaria.  
El diseño está basado en el boceto proporcionado, utilizando una estética minimalista con tonos morados y elementos SVG personalizados.

# Tecnologias Utilizadas

- HTML5
- CSS3
- SVG

# Como usar la pagina

Al ingresar con la pagina te encontraras con un formulario para ingresar los datos de tu mascota.

1. **Mascota** 
Selecciona la especie de la mascota: gato o perro.

2. **Nombre** 
Ingresa el nombre de la mascota.

3. **Apodo**
Ingresa el apodo de la mascota. Puede ser el mismo que el nombre.

4. **Edad Aproximada**
Ingresa la edad estimada de la mascota.

5. **Sexo**
Indica si la mascota es macho o hembra.

6. **Descripcion fisica** 
Describe caracteristicas fisicas como tamaño y peso.

7. **Caracteristicas**
Permite agregar informacion adicional como color, raza, comportamiento u otras caracteristicas importantes.

8. **Fotos**
Permite subir imagenes de la mascota.
